# Apple Watch VO₂max Validation

This repository contains analysis code and data relating to two laboratory studies that validated Apple Watch VO₂max estimates against indirect calorimetry, the criterion method.

| Study | Device | Participants | Folder |
|---|---|---|---|
| Lambe R, Schumann M, Donnelly L, et al. *Accuracy of VO₂max Estimates From Apple Watch Series 10.* Mayo Clinic Proceedings: Digital Health. 2026;4(2):100357. [doi:10.1016/j.mcpdig.2026.100357](https://doi.org/10.1016/j.mcpdig.2026.100357) | Apple Watch Series 10 | 40 enrolled, 35 analysed | [`series10/`](series10/) |
| Lambe R, O'Grady B, Baldwin M, Doherty C. *Investigating the accuracy of Apple Watch VO₂ max measurements: A validation study.* PLOS ONE. 2025;20(5):e0323741. [doi:10.1371/journal.pone.0323741](https://doi.org/10.1371/journal.pone.0323741) | Apple Watch (Series 9, Ultra 2 and other models) | 30 enrolled, 28 analysed | [`series9/`](series9/) |

See the README in each study's folder for the data dictionary, analysis details and instructions for running the code.
